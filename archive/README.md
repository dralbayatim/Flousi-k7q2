# أرشيف نبض السوق (يكتبه الجالب تلقائياً — لا تعدّله يدوياً)

- **إضافة فقط:** كل قيمة مرصودة جديدة تُضاف سطراً في `obs/YYYY-MM.jsonl`، ولا يُحذف أو يُعدَّل سطر أبداً. لا حد زمني.
- **لكل قيمة:** المؤشر، القيمة (البيع والشراء منفصلان)، وقت البيانات، وقت الجلب، المصدر ورابطه، ونوعها `obs`.
- **السلامة:** `MANIFEST.json` يحفظ بصمة SHA-256 لكل ملف وسلسلة بصمات تربط كل الأسطر. الجالب يفحصها قبل الإضافة وبعدها، ويرفض أي تعديل على القديم قبل الحفظ.
- **النسخة الاحتياطية المستقلة:** الفرع `nabd-archive-backup` (تاريخ منفصل)، تُحدَّث مرة يومياً بعد فحص «إضافة فقط».
- **الاستعادة:** `node fetcher/archive.mjs restore <مجلد النسخة> archive` (تفحص النسخة، تنسخ، ثم تفحص الناتج).
- **البنك الدولي RTFX:** `node fetcher/archive.mjs rtfx <ملف.csv> <تاريخ التنزيل>` يحفظ كل تنزيل نسخةً منفصلة في `rtfx/` ببصمتها، ولا يُدمج مع المرصود ولا يُعرض في التطبيق.
- المصادر محفوظة هنا فقط؛ التطبيق لا يعرض أسماءها.
